# Identidade visual Branorte

O arquivo `logo-principal-verde-preto.png` foi extraído do manual oficial fornecido pelo proprietário, `Branding_Branorte (1).pdf`. Foi preservado sem redesenho, recoloração ou alteração de proporção.

As fontes completas Poppins Regular e Bold foram obtidas do repositório oficial Google Fonts:

- https://github.com/google/fonts/blob/main/ofl/poppins/Poppins-Regular.ttf
- https://github.com/google/fonts/blob/main/ofl/poppins/Poppins-Bold.ttf

A licença SIL Open Font License acompanha os arquivos em `OFL-Poppins.txt`.

O relatório usa o verde oficial `#01A95B`, preto `#010101`, fundo branco e o logo original. Os arquivos são servidos pelo próprio CRM; a exportação não depende de fontes externas.
